# 프롬프트 가이드 수집 및 분석

## Claude Code 프롬프트 가이드 원칙

### 1. 명확하고 구체적인 지시
- 모호한 표현 대신 구체적인 요구사항 제시
- "적절히", "필요시" 같은 표현 피하기
- 예: "이 문서를 요약하되 개인정보(이름, 이메일)는 포함하지 마세요"

### 2. 컨텍스트 제공
- 프로젝트 맥락, 아이덴티티, 운영 규칙 명시
- `Claude.md` 같은 매니페스트 파일 활용
- 작업의 배경 정보 포함

### 3. 긴 문서 처리 활용
- 최대 20만 토큰 컨텍스트 활용
- 대규모 코드베이스 리뷰, 복잡한 문서 요약에 적합

### 4. 추론 과정 명시
- 단계별 분석 과정 명시
- Chain-of-Thought 기법 활용
- 논리적 추론 과정 표현

### 5. 입력/출력 예시 제공
- 원하는 결과 형식의 예시 제공
- 구체적인 입력/출력 예시

### 6. 제약 조건 명시
- 특정 라이브러리, 프레임워크 제약
- 코드 길이, 성능 요구사항 등

## ChatGPT 프롬프트 가이드 원칙

### 1. 명확하고 구체적인 질문
- 모호한 질문 피하기
- 구체적인 요구사항 포함

### 2. 맥락 제공
- 질문에 대한 배경 정보 제공
- 시점이나 상황 명시

### 3. 예시 활용
- 원하는 답변 형식이나 스타일 예시 제시
- 입력/출력 예시 제공

### 4. 단계별 지시
- 복잡한 작업을 단계로 분할
- 순차적 처리 유도

### 5. Chain-of-Thought
- 추론 과정을 명시적으로 표현
- 단계별 사고 과정 요청

## 평가 기준

### 가이드 준수 메트릭

1. **명확성 (Clarity)**
   - 모호한 표현 감지 ("적절히", "필요시" 등)
   - 구체적인 동사 사용 ("생성", "수정", "삭제")
   - 명확한 목표 제시

2. **컨텍스트 제공 (Context)**
   - 프로젝트 정보 포함
   - 배경 정보 제공
   - 관련 파일/코드 참조

3. **예시 제공 (Examples)**
   - 입력/출력 예시 포함
   - 원하는 형식 예시
   - 샘플 데이터 제공

4. **구조화 (Structure)**
   - 단계별 지시
   - 섹션 구분
   - 체계적 구성

5. **제약 명시 (Constraints)**
   - 제약 조건 명시
   - 제한 사항 명확히

## 개선 제안 템플릿

### 명확성 개선
- "모호한 표현을 구체적으로 수정하세요"
- "동사로 시작하는 명확한 지시로 변경"

### 컨텍스트 추가
- "프로젝트 배경 정보를 추가하세요"
- "관련 파일 경로나 맥락을 포함하세요"

### 예시 추가
- "입력/출력 예시를 제공하세요"
- "원하는 형식의 샘플을 포함하세요"

### 구조화 개선
- "작업을 단계로 나누어 표현하세요"
- "체계적인 섹션 구조를 사용하세요"
