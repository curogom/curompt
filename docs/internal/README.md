# 내부 문서

이 디렉토리는 **프로젝트 내부 개발 및 전략 문서**를 포함합니다.

## ⚠️ 주의사항

이 문서들은 다음과 같은 경우를 위해 작성되었습니다:
- 프로젝트 내부 개발 프로세스 기록
- 의사결정 과정 및 배경 추적
- 향후 개발 계획 수립

**공개 저장소로 전환 시 이 디렉토리는 제외하거나 별도 관리가 필요할 수 있습니다.**

## 문서 구성

### `development/`
개발 프로세스 및 계획 문서

### `strategy/`
비즈니스 전략 및 라이선스 검토 문서

---

이 문서들은 프로젝트 내부 참고용이며, 일반 사용자나 기여자에게는 필수가 아닙니다.
