# 간단한 라이선스 전략 (아이디어 도용 방지 중심)

## 목표 재정의

**주 목적:**
- ✅ 성과 및 아이디어 도용 방지
- ✅ Public 저장소 공개 (포트폴리오, 마케팅)
- ❌ 수익화는 목적 아님

**원칙:**
- "적당히만" - 복잡하지 않게
- 명확한 Attribution (출처 표기)
- 무단 복제 방지

---

## 추천: 간단한 커스텀 라이선스

### 옵션 1: Attribution + No Commercial Clone (추천)

```markdown
# CuroGom License

Copyright (c) 2025 CuroGom. All Rights Reserved.

이 소프트웨어는 다음 조건 하에 사용할 수 있습니다:

✅ 허용:
- 개인적, 교육적, 연구 목적 사용
- 소스 코드 보기, 학습, 포크
- 수정 및 개선 제안 (Pull Request)

⚠️ 제한:
- 이 프로젝트를 기반으로 한 **동일/유사한 제품의 상업적 배포** 금지
- 아이디어 및 구조의 무단 복제 금지
- 출처 표기 없이 사용 금지

사용 시 다음을 명시해야 합니다:
- "Based on curo-prompt by CuroGom" 또는 유사한 attribution

**이 라이선스는 CuroGom의 명시적 허가 없이 상업적 복제를 방지하기 위한 것입니다.**
```

**장점:**
- ✅ 매우 간단하고 명확
- ✅ 아이디어 도용 명확히 제한
- ✅ Public 저장소 적합
- ✅ Attribution 강제

**단점:**
- ⚠️ "동일/유사한 제품" 판단이 모호할 수 있음
- ⚠️ 법적 검토 필요할 수 있음

### 옵션 2: Apache 2.0 + 추가 제한 (더 안전)

```markdown
이 소프트웨어는 Apache License 2.0을 따르되, 다음 추가 제한이 적용됩니다:

추가 제한:
- 이 프로젝트의 핵심 아이디어나 구조를 무단으로 복제한 제품의 
  상업적 배포는 CuroGom의 사전 서면 동의 없이 금지됩니다.
- Attribution은 Apache 2.0 요구사항에 더해 더 명확히 표기해야 합니다.
```

**장점:**
- ✅ 표준 라이선스 기반 (법적 안정성)
- ✅ 추가 제한으로 아이디어 보호
- ✅ GitHub에서 자동 인식 (Apache 2.0)

**단점:**
- ⚠️ 약간 복잡할 수 있음
