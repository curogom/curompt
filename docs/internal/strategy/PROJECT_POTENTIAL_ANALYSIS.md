# curompt 프로젝트 가능성 분석

> 작성일: 2025-11-02  
> 분석 기준: 시장성, 기술적 우위, 확장성, 수익화 가능성

## 📊 종합 평가: ⭐⭐⭐⭐☆ (4/5)

### 강점 (Strengths)

#### 1. 시장 타이밍 ⭐⭐⭐⭐⭐
- **LLM 프롬프트 엔지니어링의 폭발적 성장**
  - ChatGPT, Claude, Codex 등 LLM 도구의 일상화
  - 프롬프트 최적화에 대한 수요 급증
  - 프롬프트 엔지니어링이 새로운 직업군으로 각광

- **타겟 시장 명확**
  - 개발자 (가장 큰 시장)
  - AI 도구 활용 기업
  - 프롬프트 엔지니어링 교육 기관

#### 2. 기술적 차별화 ⭐⭐⭐⭐☆
- **통합 수집 기능**: 단일 도구로 여러 LLM 도구의 프롬프트 수집
  - Claude Code, Codex, Cursor IDE 통합
  - 로그 파일 기반 자동 수집
  - 다른 도구들은 대부분 수동 입력

- **가이드 기반 평가**: 실제 프롬프트 가이드를 반영한 평가
  - Claude/ChatGPT 공식 가이드 준수 분석
  - 도구별 특화 평가 (Claude Code vs ChatGPT)

- **자동화된 워크플로우**
  - 수집 → 평가 → 리포트 → 개선 제안 일괄 처리
  - CI/CD 통합 가능 (자동 품질 체크)

#### 3. 확장성 ⭐⭐⭐⭐⭐
- **모듈화된 아키텍처**
  - Collector, Analyzer, Scorer 분리
  - 새로운 도구 추가 용이 (Strategy 패턴)
  - 플러그인 시스템 확장 가능

- **확장 가능한 기능**
  - M2: 동적 평가 (실제 LLM 호출)
  - M3: 자동 리팩토링
  - M4: 팀 단위 프리미엄 기능

#### 4. 수익화 가능성 ⭐⭐⭐⭐☆
- **프리미엄 기능 전략**
  - 개인용: 무료/오픈소스
  - 팀용: 프리미엄 기능 (협업, 히스토리, 대시보드)
  - 기업용: 엔터프라이즈 기능 (보안, 규정 준수)

- **서비스화 가능**
  - SaaS 버전 (웹 대시보드)
  - API 서비스 (평가 API)
  - 컨설팅 (프롬프트 최적화 서비스)

### 약점 (Weaknesses)

#### 1. 경쟁 환경 ⚠️
- **기존 도구들**
  - PromptPerfect, PromptLayer (평가/최적화)
  - 단, 수집 기능은 curompt만의 차별점

- **빠른 시장 변화**
  - LLM 도구의 빠른 발전
  - 새로운 도구 출현 시 지원 필요

#### 2. 기술적 제약
- **대화형 세션 수집의 어려움**
  - Claude Code 대화형 세션 (현재 부분 지원)
  - 실시간 프로세스 모니터링 필요

- **동적 평가의 복잡성**
  - M2에서 실제 LLM 호출 필요
  - API 비용 및 지연 시간 고려

#### 3. 시장 교육 필요
- **프롬프트 평가의 중요성 인식**
  - 개발자들이 평가 도구의 필요성 인식 필요
  - 시장 교육 및 마케팅 필요

  2. GitHub Stars 1K+ 달성

  4. 프리미엄 기능 출시 (팀 협업)

- **예상 수익**: $5K-20K/월 (초기)

- **도구**: curompt를 컨설팅 도구로 활용
